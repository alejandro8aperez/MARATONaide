# MARATONAIDE

**42.195 metros · 7 tarjetas · 1 herencia.**

Un hombre de cincuenta y dos años hereda de su padre —profesor de cálculo que murió con un dorsal en los labios— siete tarjetas cifradas con el cuerpo. Para leerlas tiene que correr la maratón de Medellín, veintiún capítulos, un prólogo y 42.195 metros.
